# Gameplay sprite assets

These PNGs were cut from the included `assets/source/character-atlas-source.png` concept sprite atlas and alpha-segmented for use by the canvas renderer.

- `hero-front.png`, `hero-side.png`, `hero-back.png`: crawler facing directions
- `hero-slash.png`, `hero-strike.png`: melee action poses / effects
- `skeleton.png`, `goblin.png`, `spider.png`, `wraith.png`: regular enemy types
- `archer.png`, `shaman.png`: ranged / magic enemy types
- `spider-boss.png`, `bone-champion.png`: floor guardians

The current runtime uses directional stills and a brief attack-pose swap. Full multi-frame walk, hit, cast, and death animation sets remain a later art milestone.
