# Crawler Survival — Mobile Action Prototype v2

Controls: hold and drag the virtual joystick; Strike attacks in facing direction; Arc Pulse is an area attack; Dodge gives a short burst and brief invulnerability; Tonic heals. Desktop: WASD/arrows, Space, Shift, E.

This build uses a fixed-timestep simulation, world-space collision, a camera-follow transform shared by all world objects, and a screen-fixed joystick. The dungeon art is procedurally rendered pixel-style masonry, floors, pillars, torch lighting, player and enemy sprites.

Publish: extract ZIP on iPhone → upload extracted files to the root of a GitHub repo → enable GitHub Pages from main / root → open HTTPS site in Safari → Share → Add to Home Screen.

Prototype limitations: no multiplayer, persistent campaign saves, authored sprite-sheet animation, sound, app-store packaging, or full device QA. Not yet a commercial release.
